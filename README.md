# 영수증 증빙서 PDF 생성기

영수증 사진(JPG/JPEG) 여러 장을 올리면 크기를 맞춰 A4 가로 페이지에 정렬한 "증빙서" PDF로 만들어 주는 브라우저용 로컬 도구입니다.

## 사용 방법

설치나 빌드 없이 `index.html`을 더블클릭해 브라우저에서 엽니다.

1. **영수증 사진 업로드** — 사진을 업로드 영역에 끌어다 놓거나 클릭해서 선택합니다. 여러 장을 한 번에 선택할 수 있고, 선택한 순서대로 배치됩니다.
2. **증빙서 정보 입력** — 계정과목, 사용자, 증빙구분(개인카드/법인카드), 증빙월, 총금액(원), 페이지당 장수(3~6장)를 입력합니다. 계정과목·사용자·총금액은 필수입니다.
3. **PDF로 만들기** — 버튼을 누르면 사진을 자동으로 회전·축소해 배치하고, 모든 페이지 하단에 증빙서 정보 표를 넣은 PDF를 만듭니다. 완성되면 미리보기가 표시됩니다.
4. **다운로드** — "다운로드" 버튼으로 PDF를 저장합니다. 파일명은 계정과목에 따라 `출장_사용비용_증빙서(식비).pdf`처럼 정해집니다. 다시 만들려면 "새로 만들기"를 누릅니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 마크업 (업로드 영역, 증빙서 정보 입력 폼, 결과 미리보기/다운로드). PDF 라이브러리(jsPDF)를 CDN으로 불러옵니다. |
| `style.css` | 화면 스타일 |
| `script.js` | 모든 동작 로직 — JPEG 검증(시그니처·손상 여부·EXIF 방향), 페이지 배치 계산, 이미지 회전·축소(canvas), PDF 조립(jsPDF), 화면 이벤트 처리 |

배포할 때는 위 세 파일만 함께 전달하면 됩니다. (`samples/`는 수동 테스트용 이미지입니다.)

## 제약사항

- **JPG/JPEG만 지원** — 확장자와 실제 파일 시그니처를 모두 검사합니다. PNG, HEIC 등은 지원하지 않습니다.
- **최대 50장**, **장당 20MB 이하** — 초과하면 안내 메시지가 표시됩니다.
- **최소 1장** 이상 업로드해야 PDF를 만들 수 있습니다.
- 손상되어 읽을 수 없는 이미지는 제외하고 나머지 사진으로 계속 진행합니다.
- 페이지는 **A4 가로 고정**이며, 사진은 원본 비율을 유지한 채 축소만 합니다(자르거나 늘리지 않음).
- 사진 방향은 EXIF 방향 정보로만 자동 회전합니다. 기울기/원근 보정, 영수증 영역 자동 자르기, 금액·날짜 인식은 지원하지 않습니다.
- 모든 처리는 브라우저 안에서 이루어지며 사진이 외부로 전송되지 않습니다. 단, **처음 실행할 때 jsPDF 라이브러리를 CDN에서 받기 위해 인터넷 연결이 필요**합니다.
- PDF 속 한글(제목, 표)은 이미지로 들어가므로 텍스트로 선택·검색되지 않습니다.
